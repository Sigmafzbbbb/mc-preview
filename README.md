# Minecraft Litematic 3D 投影预览工具

一个基于 Web 的 Minecraft Litematic 文件查看器，支持 3D 投影预览、贴图设置、网格调整等功能。

## 🚀 在线部署

项目已部署在：**https://mc-preview.sigmafzbbbb.dpdns.org**

## 📋 项目功能

- ✅ Litematic 文件上传与解析
- ✅ 3D 投影预览（基于 Three.js）
- ✅ 方块体素渲染
- ✅ 贴图配置与管理
- ✅ 网格辅助显示
- ✅ 坐标轴辅助显示
- ✅ 自动旋转功能
- ✅ 图层过滤
- ✅ Y 轴位置调整
- ✅ 网格大小调整

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **3D 渲染**: Three.js
- **文件解析**: 原生 JavaScript（NBT 格式解析）
- **UI 框架**: 原生 DOM 操作 + CSS Flexbox/Grid

## 🚀 快速开始

### 本地运行

1. 克隆或下载项目到本地
2. 确保已安装 Node.js
3. 运行 `启动服务器.bat` 启动本地服务器
4. 在浏览器中打开 `http://localhost:8080`

### 在线访问

直接访问：**https://mc-preview.sigmafzbbbb.dpdns.org**

## 📖 使用说明

### 上传 Litematic 文件

1. 点击"上传 Litematic 文件"按钮
2. 选择你的 `.litematic` 文件
3. 等待文件解析完成
4. 3D 投影将自动显示

### 贴图设置

1. 在贴图设置页面中，可以为每个方块配置 6 个面的贴图
2. 支持上传自定义贴图
3. 支持贴图旋转操作
4. 支持导出/导入贴图配置

### 视图控制

- **旋转**: 鼠标左键拖动
- **平移**: 鼠标右键拖动
- **缩放**: 鼠标滚轮
- **自动旋转**: 点击"自动旋转"按钮开启/关闭

### Y 轴调整

- 使用"上移"/"下移"按钮调整整个投影的垂直位置
- 点击"重置 Y 轴"恢复默认位置

## ⚠️ 已知问题

以下功能尚未完善，需要进一步开发：

1. **贴图方向自动检测**: 部分方块的贴图方向不正确，需要根据方块属性（facing、direction、axis）自动检测并调整贴图朝向
2. **方块位置准确性**: 部分方块的渲染位置可能存在偏差，需要优化坐标计算逻辑
3. **贴图文件缺失**: 很多方块缺少对应的纹理文件（404 错误），需要补充完整的贴图库
4. **性能优化**: 大型 Litematic 文件渲染时可能会有性能问题，需要优化渲染逻辑
5. **错误处理**: 需要更完善的错误处理和用户提示机制

#### 🔧 优先修复的问题

1. **贴图方向修复**: 实现自动检测方块方向并根据方向正确应用贴图
   - 需要解析 Minecraft 方块的 `facing`、`direction`、`axis` 属性
   - 根据 Three.js BoxGeometry 的面索引（[0]=east, [1]=west, [2]=top, [3]=bottom, [4]=south, [5]=north）正确分配贴图

2. **方块位置修复**: 修复方块渲染位置不准确的问题
   - 检查 Litematic 文件解析逻辑
   - 验证坐标转换是否正确

3. **贴图库完善**: 补充缺失的 Minecraft 贴图文件
   - 当前很多方块返回"没有纹理配置，将使用程序化纹理"警告
   - 需要收集完整的 Minecraft 贴图库
